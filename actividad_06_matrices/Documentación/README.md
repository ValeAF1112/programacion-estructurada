# Actividad: Arreglos y matrices
## Descripción
En este apartado tenemos algunos programas de arreglos, arreglos bidimencionales, matrices, strings y matrices o arreglos bidimencionales de strings. 
Con el objetivo de comprender commo funcionan estos tipos de datos y como los podemos utilizar en los códigos.
## Temas aplicados
- arreglos.
- ciclos.
- strings.
- matrices.
- operadores.
- condicionales.
## Compilación
gcc main.c -o programa
## Ejecución
./programa
