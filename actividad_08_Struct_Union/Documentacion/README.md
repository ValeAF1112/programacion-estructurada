# Actividad: Struct y Union
## Descripción
En este apartado tenemos un par de programas que nos ayudan a observar y comprender el funcionamiento de Struct, Union, punteros y operadores punto (.) y flecha (->). 
Al igual que nos ayudara a entender sus diferencias. 
## Temas aplicados
- Struct.
- Union.
- arreglos.
- ciclos.
- Operadores.
- operador flecha.
## Compilación
gcc main.c -o programa
## Ejecución
./programa
