# Actividad: Arreglos
## Descripción
En la carpea de código tenemos una serie de programas que muestran el funcionamiento de las estructuras condicionales (if-else, switch). 
También, en esta carpeta tenemos algunas capturas de pantalla de los códigos en funcionamiento, informacion acerca de la estructuras condicionales y explicaciones de que es lo que hace cada código. 
## Temas aplicados
- If - else.
- Switch.
- Operadores racionales.
## Compilación
gcc main.c -o programa
## Ejecución
./programa
